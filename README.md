# 🌊🚂 قطار الساحل — Coastal endless runner

لعبة هروب لا نهائي بثيم البحر (شبه Subway Surfers) — مبنية بـ **Three.js** بدون أي Build tools: افتح `index.html` في أي سيرفر ستاتيك والعب.

```bash
python3 -m http.server 8000
# http://localhost:8000/index.html
```

## اللعب
- ⬅️ ➡️ تغيير المسار • ⬆️ / مسافة قفز • ⬇️ تزحلق • 📱 السحب يعمل على الموبايل
- اهرب من القطارات، اقفز فوق الصناديق، اتزحلق تحت الحواجز، واصعد المنحدرات لتجري **فوق** القطارات
- باور-أب: 🧲 مغناطيس • 🛡️ درع • ✖️ نقاط ×2 • 🛹 لوح ينقذك مرة
- الطقس يتغير: مشمس → غروب → ليل → عاصفة (مطر + برق حقيقي)
- أفضل نتيجة محفوظة في المتصفح

## الملفات
| ملف | الوصف |
|---|---|
| `index.html` | القوائم + HUD + importmap |
| `css/style.css` | كل التنسيقات (عربي RTL) |
| `js/main.js` | اللعبة كاملة: عالم، قطارات، فيزياء، طقس، صوت |

الصوت مولّد إجرائيًا بـ WebAudio (موسيقى + أمواج + أبواق) — لا ملفات خارجية إلا Three.js من CDN.
